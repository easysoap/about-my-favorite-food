# 음식 속 영양소 탐험

5학년 실과 활동지 2쪽과 함께 쓰는 정적 웹사이트입니다. `index.html` 한 파일만으로 실행되며 서버, API 키, 별도 설치가 필요하지 않습니다.

## GitHub Pages에 올리기

1. 압축파일을 풀고 `index.html`을 GitHub 저장소의 최상위 폴더에 업로드합니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. 게시할 브랜치(예: `main`)와 **/(root)**를 선택하고 저장합니다.
4. Pages 화면에 표시되는 주소를 학생들에게 공유합니다.

기존에 GitHub Pages를 설정한 저장소라면 현재 게시 폴더에 `index.html`을 놓으세요. 이미 같은 이름의 파일이 있다면 덮어쓰기 전에 기존 파일을 백업하거나 별도 저장소를 사용하세요.

## 수업 구성

- 활동지 1쪽의 음식 24가지를 고를 수 있습니다.
- 각 음식의 흔한 재료 예시를 펼쳐 대표 영양소를 살펴볼 수 있습니다.
- 다른 음식 이름과 재료를 직접 입력할 수 있습니다. 예시 자료에 없는 재료는 식품의약품안전처 K-FIND에서 조사하도록 안내합니다.
- 이름이나 입력한 내용은 서버로 보내거나 저장하지 않습니다. 화면을 새로고침하면 직접 입력한 내용은 사라집니다.

이 사이트의 재료와 영양소 표시는 **5학년 수업을 위한 대표 예시**입니다. 재료의 종류나 개수만으로 실제 함량, 많고 적음, 음식의 균형 여부를 계산하지 않습니다. 조리법과 재료의 양을 고려해 학생이 활동지에 근거와 함께 판단하도록 구성했습니다.

정확한 식품별 함량 확인: https://www.foodsafetykorea.go.kr/fcdb/detail/search/list.do
